# Email Spam Classification Using Natural Language Processing and Machine Learning

## Project Overview

This project implements an email/message spam classification system using Natural Language Processing and Machine Learning.

The system classifies messages into two categories:

* Spam
* Not Spam

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Natural Language Processing
* TF-IDF
* Multinomial Naive Bayes
* Google Colab

## Methodology

The project follows these steps:

1. Dataset creation and preparation
2. Text cleaning
3. Label encoding
4. Train-test splitting
5. TF-IDF feature extraction
6. Multinomial Naive Bayes model training
7. Prediction
8. Model evaluation
9. Interactive spam detection

## Evaluation

The model is evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## How to Run

Open the provided Google Colab notebook and execute the cells sequentially or select Runtime → Run all.

## Applications

The basic approach demonstrated in this project can be used as a foundation for:

* Email spam filtering
* SMS spam detection
* Message classification
* Text classification systems

## Future Scope

The project can be improved using larger real-world datasets, advanced NLP techniques, word embeddings, deep learning models, and transformer-based architectures.
